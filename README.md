# DAF Trainer

Приложение с задержкой звука для занятий: голос с микрофона возвращается
в наушники через заданное число миллисекунд.

Ядро на Rust (cpal, общий режим WASAPI — тот самый тракт, который уже проверен
прототипом), интерфейс на HTML в системном движке Windows через Tauri.
Собирается в один exe.

## Сборка

Нужен Rust (уже стоит) и WebView2 — он входит в Windows 11 по умолчанию.

```
cargo build --release
```

Готовый файл: `target\release\daf-trainer.exe`

Первая сборка долгая, минут пять: Tauri тянет много зависимостей.
Дальше секунды.

Через GitHub Actions работает так же — воркфлоу в `.github/workflows/build.yml`.

## Первый запуск

1. Открыть «Настройки».
2. Выбрать вход и выход. Лучше одно и то же устройство, если оно умеет и то и другое.
3. Нажать «Измерить». Наденьте наушники, поднесите чашку к микрофону.
   Программа проиграет пять щелчков и посчитает реальную задержку тракта.
4. «Готово», выставить задержку, «Пуск».

**Важно:** выключи на PodMic USB прямое прослушивание (нажатие на колёсико
громкости, светодиод должен быть красным), иначе будешь слышать себя дважды —
мгновенно от микрофона и с задержкой от программы.

## Что уже работает

Задержка 20–400 мс и длинный режим до 4 секунд, пресеты, шаг ±10 мс,
регуляторы микрофона и выхода в дБ с индикацией клиппинга, таймер занятия
с обратным отсчётом и пресетами 15/30/40, калибровка тракта, обрезание шкалы
по реальному полу устройства, обе локализации, сохранение настроек между
запусками, две пляшущие точечные «катушки» с размерной линией задержки между ними.
